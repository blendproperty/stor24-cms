# Satoshi font credits

CMS typography uses the unmodified official Satoshi variable WOFF2 font from
Indian Type Foundry (ITF), distributed through Fontshare. ITF owns the applicable
font trademarks and copyrights. The normal variable face has a verified wght
axis from 300 to 900; downloaded 30 September 2026.

Source: https://api.fontshare.com/v2/css?f[]=satoshi@variable&display=swap
Font family: https://www.fontshare.com/fonts/satoshi
Terms: https://fontshare.com/terms

See docs/STOR24_BRAND_CI.md for provenance and SHA-256. The older Handover WOFF2
files are official static regular/bold historical assets, no longer used by CMS.
